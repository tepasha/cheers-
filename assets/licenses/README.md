# Сторонні зображення в `assets/`

`icon.png`, `adaptive-icon.png`, `splash.png`, `logo.png`, `favicon.png` зроблені з емодзі «Clinking Beer Mugs» (U+1F37B)
з **Noto Emoji** від Google: https://github.com/googlefonts/noto-emoji (`2D/svg/emoji_u1f37b.svg`), на тлі та з
сяйвом у кольорах застосунку.

Ліцензія: README репозиторію каже, що зображення в ньому розповсюджуються за **Apache License 2.0**, а шрифти — за
**SIL Open Font License 1.1**; кореневий файл LICENSE репозиторію зараз містить текст OFL 1.1 (копія:
`noto-emoji-OFL.txt`). Обидві ліцензії дозволяють використання в комерційному застосунку; ця примітка — атрибуція.
Copyright 2013 Google LLC.

Повний Apache 2.0 текст для зображень збережений у `noto-emoji-apache-2.0.txt`; атрибуція й текст також включені в застосунок через `src/data/imageLicenses.json` (Профіль → Ліцензії зображень). Для PNG зазначені зміни: фон, сяйво, кадрування та розмір. OFL файл залишений як довідка про шрифти; сам по собі він не замінює ліцензію зображень.
