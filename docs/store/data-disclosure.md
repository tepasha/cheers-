# Дані для магазинів — перевірити на release збірці

Дата звірки коду: 2026-10-07. Політика має описувати фактичні сервери й SDK вашого production середовища. Це робоча таблиця для заповнення консолей; власник відповідає за кінцеві декларації.

| Дані | Призначення | Обов'язковість |
|---|---|---|
| Email, ім'я, UID | Автентифікація, профіль | Так |
| Дата народження, згода | Заявлений вік **21+**, облік умов | Так |
| Округлений район / геолокація | Пошук у радіусі 3 км; добровільний показ себе на сітці 0,02° | GPS та публікацію можна вимкнути |
| Повідомлення й пропозиції | Чати, зашифроване зберігання, без E2EE | При використанні |
| Фото Google | Аватар | Ні |
| Події, уподобання | Соціальні функції | При використанні |
| Токен push | Доставка Expo/APNs/FCM | Ні |
| Скарги, блокування | Безпека й модерація | При використанні |
| Службова присутність | Функції Firebase, без показу lastSeen іншим людям | Так |
| Crash reports, OS, модель, версія | Sentry, діагностика збоїв | У release з DSN |

Firebase, Expo, Apple/Google та Sentry є постачальниками обробки. Повідомлення не входять у стандартний push, але токен та ID чату входять. Для JS crash reports видаляються payload, user, текст винятку й breadcrumbs; перевірте окремо нативні reports. Немає рекламних SDK, session replay або рекламного tracking. Source maps містять вихідний код і мають бути доступні лише вашій команді.

Для локації перевірте **весь** шлях на пристрої: GPS може бути точним локально, discovery центр округлений приблизно до 550 м, профіль — 0,02°, координати публічних закладів/подій можуть бути точними. Не використовуйте стару декларацію «публічна позиція до будівлі ~20 м». Вибір категорій Precise/Coarse в консолях залежить від того, які координати фактично залишають пристрій та їхніх визначень. За невизначеності декларуйте точне й приблизне збирання консервативно; рішення про категорію зафіксуйте після network перевірки release збірки.

Зазначте шифрування в транзиті, запит видалення й дані, що залишаються: повідомлення без імені/фото та псевдонімні UID, скарги до 90 днів. Вкажіть реальний публічний Delete account URL і підтримку. Видалення є для email, Google та Apple.

Перевірте privacy manifests усіх нативних SDK, дозволи foreground location, вікову анкету (алкоголь і соціальне спілкування), правила дитячої безпеки для соціальних застосунків і контакт модерації. Окремо узгодьте export compliance для AES у застосунку: прапорець у конфігурації не замінює визначення винятку.

Джерела: [Apple App Review](https://developer.apple.com/app-store/review/guidelines/), [Google account deletion](https://support.google.com/googleplay/android-developer/answer/13327111), [Google Data safety](https://support.google.com/googleplay/android-developer/answer/10787469).
